# Introdução à Programação em C

Este repositório contém uma coleção de exercícios, algoritmos e projetos desenvolvidos durante a disciplina de **Introdução à Programação**. O objetivo deste material é consolidar os fundamentos da linguagem C, explorando desde conceitos básicos até estruturas de dados e lógica de programação avançada.

## Estrutura do Repositório

O projeto está organizado com nomes descritivos para facilitar o estudo e a navegação:

*   **`exercicios/`**: Diversas listas de exercícios práticos categorizados.
    *   `basicos/`: Lógica inicial, loops, condicionais e manipulação simples de dados.
    *   `intermediarios/`: Jogos simples, cálculos matemáticos e manipulação de tipos.
    *   `ponteiros/`: Aritmética de ponteiros, referências e memória.
    *   `recursao/`: Algoritmos recursivos (fatorial, soma de vetores).
    *   `struct/`: Organização de dados com estruturas.
*   **`desafios/`**: Problemas complexos como validação de CPF e manipulação de matrizes quadradas.
*   **`projetos/`**: Aplicações completas em C:
    *   **Jogo da Forca**
    *   **Jogo da Velha**
    *   **Pokedex** (Simulação via Terminal)

## Tecnologias Utilizadas

*   **Linguagem:** C
*   **Compilador Recomendado:** GCC (GNU Compiler Collection)
*   **Ambiente:** VS Code / Terminal Linux

## Como Executar

Para compilar e rodar qualquer um dos programas, utilize o terminal:

1.  Navegue até a pasta do arquivo.
2.  Compile:
    ```bash
    gcc nome_do_arquivo.c -o programa
    ```
3.  Execute:
    ```bash
    ./programa
    ```
